      03 Under the hood

      Built like a real server

      1. Speaks both eras of MCP. 2026-07-28 (stateless: no handshake, version and method in every request, headers checked against the body) and 2025-11-25, 2025-06-18, 2025-03-26 with the classic initialize.
      2. Seven read-only tools, three resources, three prompts. Every tool is annotated read-only and idempotent. Nothing on this server can write anything.
      3. It would rather say no. A claim it can't back comes back not_found or not_supported, with a reason. Gaps are in the data on purpose.
      4. One Worker, one JSON file. A single Cloudflare Worker reads data/career.json, the same record that powers For you. Origin-checked, rate-limited, and it stores nothing you send.
      5. Tested against the official SDK. Connects, lists and calls cleanly with the MCP TypeScript SDK client, plus 18 tests across both eras. Read the source ↗
